ทุกคำเคลมบนเว็บต้องตรวจสอบได้ ถ้าเป็นคำเด็ดขาด ("ทุก", "ทุกแบบ"), คำเปรียบเทียบที่ไม่มีข้อมูล ("เร็วขึ้น", "ไม่ทิ้งคุณภาพ") หรือเคลมความสามารถที่ไม่มี repo หรือผลงานรองรับ ให้ติด Should ขึ้นไป

**Why:** D3 / D5 — PROFILE มี Avoid "ตัวเลขผลงานที่พิสูจน์ไม่ได้" และกลุ่มหลักคือ HR คำเคลมเกินจริงทำลายความน่าเชื่อถือ ใน Lab 02 ถ้อยคำที่ผ่านคือแบบที่บอกสถานะตามจริง เช่น "กำลังลงมือกับ AI agents" และ "รีวิวโดย AI อีกตัวร่วมกับตัวเราเอง" (บอกตรง ๆ ว่าคนรีวิวคือ AI)

**How to apply:** ตอนรีวิวข้อความใน case study / About / Home ให้ถามทุก bullet ว่า "ผู้ชมตรวจได้ไหม" · ห้ามมี section ว่าง หรือเขียนว่า "เร็ว ๆ นี้" · คำเคลมต้องไม่ชี้ไปถึงบริษัทหรือลูกค้า (Private)
